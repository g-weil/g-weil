## Projeto em destaque — Fut Manager

Backend de uma aplicação para organização de partidas de futebol amador, desenvolvido com Python, FastAPI, SQLAlchemy e MySQL.

O projeto inclui:

- Cadastro, consulta, edição e exclusão de atletas.
- Formação de times considerando o nível de habilidade dos jogadores.
- Registro de partidas, placares e histórico.
- Avaliações individuais e atualização automática do rating dos atletas.
- Validações e proteção dos vínculos entre os dados.
- API REST com documentação interativa e testes automatizados.
- Menu de terminal que compartilha as mesmas regras da API.

[Conheça o projeto](https://github.com/fut-manager-labs/fut-manager)
